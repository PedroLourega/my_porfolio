# Portfolio 

Portfólio pessoal feito principalmente com Python e Flask, com foco em ser direto, clean e fácil de atualizar. A ideia é ter uma home bem apresentada, páginas separadas (Home, Projetos, Sobre, Contato) e um backend simples servindo os dados dos projetos.

## O que possui

- Tema escuro, visual limpo
- Menu responsivo (hamburger fullscreen)
- Efeito discreto seguindo o mouse apenas na Home
- Página de projetos com filtro por tags
- Projetos carregados via JSON (com plano de migrar para MongoDB)
- CSS próprio e JS enxuto

## Stacks

- Python
- Flask
- HTML/CSS/JavaScript
- Planejado: MongoDB

## Dados dos projetos

Os projetos são lidos a partir de `app/data/projects.json`.

Campos usados:
- `title`
- `description`
- `tags`
- `links.github`
- `links.demo`
